# Analog Guitar Effect Processing Console

## Overview
This project implements an analog guitar effects console, simulating and testing multiple effects, namely distortion and tremolo. This is done as a core requirement of the module EN2091 - Laboratory Practice and Projects.

## Objectives
- Simulate analog circuits for various guitar effects
- Test effects using sample guitar signals
- Provide a modular design that can be extended

## Project Files
- `report/` – Final report
- `simulation/` – Circuit simulation files
- `demo/` – Effects in action

## Development Process
- Started with circuit simulations using LTSpice
- Testing the circuit through breadboard
- Integrated effects into a consolidated console design with proper PCBs and enclosure


## Possible Future Improvements
- Add more effects (e.g., Wah, Vibrato)
- Optimize circuit for low-noise operation
- Implement digital audio processing
